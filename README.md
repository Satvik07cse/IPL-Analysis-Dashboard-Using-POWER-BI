🏏 IPL Analysis Dashboard (2008 - 2022)

This Power BI dashboard provides an in-depth visual analysis of the Indian Premier League (IPL) across 15 seasons (2008 to 2022). The dashboard allows users to explore and compare team performances, player stats, match results, and tournament insights interactively.

📌 Key Features
🏆 Season Overview (Select Season Dropdown)
Champion Team for each season

Orange Cap: Top run-scorer

Purple Cap: Highest wicket-taker

Total 4s and 6s in the tournament

🔍 Detailed Analytics
🏏 Player Statistics
🔹 Batting Insights
Select any batsman (e.g., Gautam Gambhir) to view:

Total Runs

Number of 4s and 6s

Strike Rate

🔹 Bowling Insights
Select any bowler (e.g., Shane Warne) to view:

Total Wickets

Economy Rate

Bowling Average

Strike Rate

📊 Team and Match Analysis
🏟️ Wins by Venue
Visualized by runs and wickets for each stadium

🎲 Toss Decision Impact
Comparison of match wins when choosing to bat or field after winning the toss

📈 Result Type
Matches won by wickets vs runs

🥇 Team Performance
Total wins by each team per season

🗃️ Dataset Details
Seasons Covered: 2008 to 2022

Data Includes:

Match results

Player-wise performance (batting, bowling)

Toss decisions

Stadium-wise outcomes

Source: Kaggle / Cricsheet / Official IPL stats (depending on your actual source)

🛠️ Tools & Technologies
Power BI Desktop: For building interactive visuals

DAX: Used for custom measures and KPIs

Excel / CSV: For data cleaning and merging across seasons

🚀 How to Use
Open the .pbix file in Power BI Desktop

Use the "Select Season" dropdown to filter between 2008 and 2022

Click on a batsman or bowler name to view individual stats

Hover over visuals for interactive tooltips

📈 Key Insights Across 15 Seasons
Consistency of top teams like CSK and MI

Dominance of players like Virat Kohli, David Warner, Lasith Malinga, and Jasprit Bumrah

Toss decisions and match venues significantly influencing results

Sharp rise in 4s and 6s over the years, indicating aggressive gameplay trends
